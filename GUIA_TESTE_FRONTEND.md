## 🚀 ONBOARDING DO SISTEMA

### O que é?
Um guia passo-a-passo que apresenta as principais funcionalidades do sistema para novos usuários.

### Como acessar?
O onboarding é exibido automaticamente no primeiro acesso. Para visualizar novamente:
1. Limpe o localStorage (`localStorage.removeItem('onboardingCompleted')`) ou use uma aba anônima.
2. Acesse `/onboarding` diretamente (se logado).

### Etapas do Onboarding:
1. **Boas-vindas**: Apresentação do sistema.
2. **Contatos**: Como gerenciar sua base de contatos.
3. **Segmentação**: Como filtrar por região e área.
4. **Campanhas**: Como criar e enviar mensagens.
5. **Agendamento**: Como programar envios futuros.
6. **Analytics**: Como acompanhar os resultados.
7. **Conclusão**: Pronto para começar!

### Características:
- ✅ Navegação intuitiva (Próximo/Anterior)
- ✅ Indicador de progresso
- ✅ Opção de pular tutorial
- ✅ Design visual com ilustrações
- ✅ Persistência (não mostra novamente após concluir)
